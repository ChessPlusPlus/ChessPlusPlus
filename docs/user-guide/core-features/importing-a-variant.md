# Importing A Variant

After exporting a JSON file of a variant, it can be imported back into the website!&#x20;

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

Click on "Import variant", then choose a name for this variant and select a file from your computer to import.

<figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Warning: If the JSON file you import is not in the correct format, an error will show and you will be unable to import that JSON file.
{% endhint %}

Now, you can go on and edit or play that variant you just imported.

Warning: Due to the fact that the JSON file does not have the function to hold images, all piece images in a newly imported variant will be set to the [default image](#user-content-fn-1)[^1]. This would be changed very soon in the next update.
