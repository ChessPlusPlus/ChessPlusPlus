# Exporting As JSON

Good news! The custom variant you made is not eternally bound to your device. You can export the whole variant as a JSON file and send it to anyone you wish.

<figure><img src="../../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

Over on the right, you can click "**Export JSON**" and then input a file name to download the JSON file.

<figure><img src="../../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Warning: The JSON file of a variant does not contain the piece images. This is a feature planned to be added very soon in a future update.
{% endhint %}

You can edit the JSON to your liking, however that is not recommended as you might accidently cause some unexpected behaviour.
